# 🟢 Easy LeetCode Practice List 🚀

Beginner-friendly LeetCode questions to build logic, confidence,  
and DSA intuition step by step.

---

## 🟢 EASY ARRAY / LOOP (Beginner Confidence)

### 136. Single Number
- Every element appears twice except one.
- Find the element that appears only once.
- **Hint:** XOR  
- **Time:** O(n)

---

### 121. Best Time to Buy and Sell Stock
- Buy once, sell once to get maximum profit.
- **Hint:** Track minimum price so far.
- **Time:** O(n)

---

### 88. Merge Sorted Array
- Merge `nums2` into `nums1` in sorted order (in-place).
- **Hint:** Start merging from the back.
- **Time:** O(m + n)

---

### 977. Squares of a Sorted Array
- Square each element and return sorted result.
- **Hint:** Two pointers.
- **Time:** O(n)

---

### 905. Sort Array By Parity
- Place even numbers first, then odd numbers.
- **Hint:** Two pointers.
- **Time:** O(n)

---

## 🟢 EASY STRING / HASHING

### 387. First Unique Character in a String
- Return index of first non-repeating character.
- **Hint:** Frequency count.
- **Time:** O(n)

---

### 383. Ransom Note
- Check if ransom note can be constructed from magazine letters.
- **Hint:** Character frequency.
- **Time:** O(n)

---

### 125. Valid Palindrome
- Check palindrome ignoring case and non-alphanumeric characters.
- **Hint:** Two pointers.
- **Time:** O(n)

---

## 🟡 EASY BUT THINKING REQUIRED

### 66. Plus One
- Add one to number represented as array.
- **Hint:** Handle carry from right.
- **Time:** O(n)

---

### 268. Missing Number
- Find missing number from range `[0, n]`.
- **Hint:** Sum formula or XOR.
- **Time:** O(n)
